1) يعني إيه Form؟

كلمة Form معناها نموذج. تخيّل استمارة ورقية بتكتب فيها اسمك وسنك، لكن بدل الورقة بنحط خانات جوه صفحة ويب.

أمثلة من حياتنا

  • تسجيل طالب في كورس.
  • تسجيل الدخول لحساب.
  • إرسال رسالة لفريق الدعم.
  • البحث عن منتج.

العنصر الأساسي

بنستخدم عنصر <form> علشان نجمع الحقول المرتبطة ببعض في نموذج واحد.

مهم: HTML بيحدد شكل الحقول وقواعد بسيطة، لكنه لوحده مش بيحفظ البيانات في قاعدة بيانات.

🧩

2) أهم العناصر والخصائص

<input> — خانة إدخال

العنصر ده ليه أنواع كتير، وبنحدد النوع باستخدام الخاصية type.

أمثلة على أنواع input
<input type="text">       <!-- نص عادي -->
<input type="email">      <!-- بريد إلكتروني -->
<input type="password">  <!-- كلمة مرور -->
<input type="number">     <!-- رقم -->
<input type="date">       <!-- تاريخ -->
<input type="tel">        <!-- رقم تليفون -->
<input type="checkbox">  <!-- اختيار مستقل -->
<input type="radio">      <!-- اختيار من مجموعة -->

<label> — اسم الحقل

بيوضح للمستخدم يكتب إيه. أفضل طريقة نربطه بالحقل عن طريق for مع id متطابقين.

ربط صحيح
<label for="studentName">اسم الطالب</label>
<input id="studentName" name="studentName" type="text">
خلي بالك: قيمة for لازم تطابق قيمة id الخاصة بالحقل بالضبط.

<textarea> و<select>

textarea لرسالة أو ملاحظات طويلة، وselect لعرض قائمة اختيارات.

مربع رسالة وقائمة اختيار
<label for="notes">ملاحظات</label>
<textarea id="notes" name="notes" rows="4"></textarea>

<label for="course">اختار الكورس</label>
<select id="course" name="course">
  <option value="scratch">Scratch</option>
  <option value="python">Python</option>
  <option value="frontend">Front-End</option>
</select>
⚙️

3) خصائص لازم نفهمها

id

معرّف فريد بنستخدمه لربط الـ label أو التعامل مع العنصر لاحقًا.

name

اسم الحقل اللي غالبًا بيتبعت مع البيانات عند إرسال النموذج.

placeholder

نص إرشادي مؤقت جوه الحقل، لكنه مش بديل عن label.

required

بيطلب من المستخدم يملأ الحقل قبل الإرسال.

value

القيمة المرتبطة بالحقل أو الاختيار، حسب نوع العنصر.

min وmax

يقدروا يحددوا أقل وأكبر قيمة في بعض أنواع الحقول زي number وdate.

التحقق الموجود في HTML مفيد لتجربة المستخدم، لكنه مش كفاية لحماية البيانات في تطبيق حقيقي. لازم التحقق من البيانات على الخادم كمان.
💻

4) تطبيق عملي: نموذج تسجيل طالب

هنبني نموذج فيه الاسم والبريد والسن والكورس ورسالة اختيارية وزر إرسال. جرّب تقرأ الكود وتحدد وظيفة كل جزء.

الكود الكامل — انسخه في ملف form.html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>تسجيل طالب</title>
</head>
<body>
  <h1>تسجيل طالب جديد</h1>
  <form action="#" method="get">
    <label for="name">اسم الطالب:</label>
    <input id="name" name="name" type="text" required>

    <label for="email">البريد الإلكتروني:</label>
    <input id="email" name="email" type="email" required>

    <label for="age">السن:</label>
    <input id="age" name="age" type="number" min="7" max="18" required>

    <label for="course">الكورس:</label>
    <select id="course" name="course" required>
      <option value="">اختار كورس</option>
      <option value="scratch">Scratch</option>
      <option value="python">Python</option>
      <option value="frontend">Front-End</option>
    </select>

    <label for="notes">ملاحظات (اختياري):</label>
    <textarea id="notes" name="notes" rows="4"></textarea>

    <button type="submit">إرسال البيانات</button>
  </form>
</body>
</html>
ملاحظة تعليمية: استخدمنا action="#" وmethod="get" للتجربة المحلية فقط. البيانات ممكن تظهر في عنوان الصفحة بعد الإرسال، ومفيش قاعدة بيانات أو إرسال حقيقي هنا. ما تدخلش بيانات شخصية حقيقية في التجربة.
🧪

جرّب بنفسك

  1. ابني الملف وشغّله في المتصفح.
  2. حاول تضغط إرسال من غير ما تكتب الاسم أو البريد، ولاحظ التحقق.
  3. اكتب بريدًا بصيغة غير صحيحة ولاحظ رسالة المتصفح.
  4. أضف اختيارًا جديدًا للكورس.
👀

5) معاينة نموذج للتجربة

النموذج التالي للمعاينة فقط؛ لا يرسل أو يخزن بيانات.

🛠️

6) أخطاء شائعة وإزاي نصلحها

الـ label مش بيركز على الحقل

السبب غالبًا إن for مختلف عن id. خلّي القيمتين متطابقتين.

الحقل مش بيتبعت باسمه

تأكد إنك كتبت خاصية name، لأنها مهمة عند إرسال بيانات النموذج.

زر الإرسال مش بيعمل المطلوب

استخدم <button type="submit"> داخل الفورم. وجود الزر وحده مش معناه إن البيانات هتتحفظ في قاعدة بيانات.

كتبت placeholder بدل label

الـ placeholder بيختفي عند الكتابة ومش بديل واضح عن label؛ استخدم الاتنين عند الحاجة.

✍️

7) تمارين أثناء المحاضرة

  1. تمرين 1: أنشئ حقلًا لاسم ولي الأمر، واجعله مطلوبًا.
  2. تمرين 2: أضف حقل رقم تليفون باستخدام النوع المناسب.
  3. تمرين 3: أضف قائمة اختيار للمستوى: مبتدئ، متوسط، متقدم.
  4. تمرين 4: أضف اختيارين بـ radio للسؤال: هل درست برمجة قبل كده؟ نعم / لا. اجعل لهما نفس قيمة name وقيمتين مختلفتين لـ value.
  5. تحدي: أضف checkbox للموافقة على سياسة الخصوصية، واجعله مطلوبًا.
شوف مثالًا لحقل تليفون
<label for="phone">رقم التليفون:</label>
<input id="phone" name="phone" type="tel" required>

type="tel" يساعد على اختيار إدخال مناسب، لكنه لا يتحقق وحده من صحة كل صيغ أرقام التليفون.

9) الواجب المنزلي

المطلوب تسليمه

  1. ملف HTML اسمه student-registration.html.
  2. نموذج تسجيل كامل بالمواصفات الموجودة في المشروع.
  3. إضافة حقل تاريخ باستخدام type="date" لو محتاج تاريخ ميلاد تجريبي.
  4. تأكد إن كل حقل له label مرتبط بيه وإن الحقول المطلوبة عليها required.
  5. اكتب تحت الكود 3 سطور: الفرق بين id وname وplaceholder.
إضافة للطلاب المتقدمين: جرّب استخدام fieldset وlegend لتجميع الحقول المتعلقة ببعض، مثل بيانات الطالب وبيانات ولي الأمر.
📝

10) مراجعة سريعة

1. إيه وظيفة form؟
تجميع حقول إدخال البيانات في نموذج واحد.
2. إيه الفرق بين text وemail؟
text للنص العادي، أما email فيوفّر تحققًا مبدئيًا من صيغة البريد.
3. ليه بنستخدم label؟
علشان نوضح معنى الحقل ونربطه به، وده بيسهّل استخدام النموذج.
4. هل required بيحفظ البيانات؟
لا، هو بيطلب ملء الحقل قبل الإرسال. الحفظ والإرسال الحقيقي يحتاجان جهة تستقبل البيانات مثل خادم.
5. إيه الفرق بين id وname؟
id معرّف للعنصر داخل الصفحة، وname اسم الحقل المستخدم عادةً ضمن البيانات المرسلة.

📌 ملخص المحاضرة

  • form بيجمع عناصر النموذج.
  • input له أنواع مختلفة حسب البيانات.
  • label لازم يرتبط بالحقل عن طريق for وid.
  • textarea للنصوص الطويلة وselect لقائمة الاختيارات.
  • required وmin وmax بيساعدوا في التحقق المبدئي.
  • HTML وحده مش بيحفظ البيانات في قاعدة بيانات.
